# MAP Edition Group Limited — Website

Premium corporate website for **MAP Edition Group Limited**, built with Next.js, TypeScript, and Tailwind CSS.

## Getting started

```bash
cd website
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — start development server
- `npm run build` — production build
- `npm run start` — serve production build
- `npm run lint` — run ESLint

## Stack

- Next.js App Router
- React 19
- Tailwind CSS 4
- Framer Motion
- Lucide Icons

## Project structure

- `src/app/` — pages and API routes
- `src/components/` — layout, sections, forms, UI
- `src/lib/` — data, SEO helpers, utilities
